# Support and contribution

Global Torque frontend maintainers own this package. Use the vue-ui issue
tracker with the exact package version, runtime, reproduction and expected
behavior. Changes require type, behavior, clean-artifact and browser checks.
Breaking changes to supported APIs receive a minor version before 1.0 and a
major version afterward. Patch releases preserve the documented API.

Rollback: pin the previous reviewed artifact/version and repeat consumer tests.
Never replace a published archive; publish a verified patch instead.
