# Upstream attribution

`@global-torque/ui-primitives` is our canonical low-level UI code. Every
component starts as a copy generated by the official shadcn-vue CLI and is then
owned here: we may edit it for accessibility, typing or API, never for brand
values. Workspace presets live in `src/styles/presets/`; they are excluded
from the public artifact, whose consuming host supplies theme values. This file is the only record of
where the code came from and what we changed.

| | |
|---|---|
| Generator | `shadcn-vue` CLI 2.8.2, `pnpm dlx shadcn-vue@2.8.2 add <item>` |
| Registry | https://www.shadcn-vue.com, style `new-york-v4` (Tailwind v4) |
| Upstream mirror at generation time | `unovue/shadcn-vue` `dev` at `dd3ff4cc` (2026-08-26) |
| Runtime dependencies | `vue`, `reka-ui` (peers), `class-variance-authority`, `clsx`, `tailwind-merge`, `@vueuse/core`, `@lucide/vue` |
| Not a source | the `ui-kit.webdevelop.pro` fork and its `@webdevelop-pro/ui-primitives@0.0.1` package |

Post-generation rewrites applied by `scripts/add.mjs` to every file:

- `@/lib/utils` → relative `../lib/utils` (consumers resolve the package source without aliases);
- `lucide-vue-next` → `@lucide/vue`.
